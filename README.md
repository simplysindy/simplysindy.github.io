# simplysindy.github.io

Personal portfolio site — built with Next.js, TypeScript, and Tailwind CSS.

## Featured Projects

- **AI Werewolf** — Discord bot with AI agents playing One Night Ultimate Werewolf
- **Kube** — Real-time crypto sentiment analysis pipeline on Kubernetes
- **Adversarial AI Security** — Backdoor attack detection in neural networks
- **EtherShield** — Ethereum wallet risk classifier with explainability reports

## Tech Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion

## Development

```bash
npm install
npm run dev
```
